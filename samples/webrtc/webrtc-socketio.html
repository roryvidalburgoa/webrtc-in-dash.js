Usage Instructions:
  • Enter your Socket.io server URL (e.g., wss://camera.geometris.com)
  • Enter the device serial number and APIKey
  • Optionally configure ICE servers in JSON format for restrictive networks
  • Configure retry settings: max attempts (default: 3) and delay between retries (default: 2000ms)
  • Click "Connect" to start the WebRTC stream
  • The library will automatically retry on connection failure with configured settings
  • Use "Switch Camera" to toggle between front and back cameras
Restrictive Network Support:
  • Default configuration includes multiple STUN/TURN servers for better connectivity
  • Automatic retry logic helps establish connections in challenging network conditions
  • Configure additional ICE servers if your network requires specific TURN servers

URL Parameters:

  • ?serialnumber=XXX - Pre-fill serial number
  • ?apiKey=XXX - Pre-fill Encoded APIKey
  • ?debug=1 - Load debug localhost settings
  • ?qa=0 - Load production defaults
